# Reference Values — TARE Model

Validated baseline numbers from past model runs, used to confirm whether a code change moved a modeled output (and by how much). Moved out of `CLAUDE.md` on 17 September 2026 to keep that file focused on standing rules rather than historical data — nothing below was reworded or reordered when it moved.

**When to open this file:** before citing any modeled quantity (an NPV, an adoption rate, a fuel cost, a climate-damage figure) in code, comments, or conversation with the researcher; before/after comparing a fresh run's output to a prior one; or when deciding whether a code change is expected to move a modeled value.

**Release vintage — read this before comparing anything here to a ResStock 2025.1 run.** Every row below was measured on **ResStock 2022.1.1 (EUSS, AMY2018)**: uniform weight 242.131013 per representative dwelling unit, a 331,531-rdu national frame, and the MP3 / MP4 measure packages. The `Data vintage` column records the anchor-year window of the cost stream (2025–2039 after the 12 Aug 2026 fix), **not** the ResStock release — so it does not distinguish the two releases.

Work on ResStock 2025.1 began with a read-only audit on 18–19 September 2026 (`docs/AUDIT_2026-09-18_ResStock2025_1_DualFuel.md`). **No 2025.1 reference value exists yet**, because the 2025.1 pipeline has not been run. Do not compare a 2025.1 output against any row in this table and read the difference as a code regression: the two releases differ in weight per rdu (253.90367272727272 vs 242.131013), published row count (549,971 vs 548,916), measure packages (Upgrade 05 dual fuel and Upgrade 04 cold-climate ASHP vs MP3/MP4 — the numbering does not carry over), and column naming. When 2025.1 values are first derived, add them as new rows carrying an explicit release label rather than superseding anything below; these 2022.1.1 rows stay valid for the 2022.1.1 pipeline, whose oracle run `2026-09-02_19-04` must keep reproducing byte-identically.
